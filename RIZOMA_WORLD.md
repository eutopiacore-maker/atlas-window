# Atlas Reality Stack — Rizoma World

The live world is organized as **Rizoma Ω**, not as a pipeline.

Authoritative nodes and surfaces:

- `world-engine.js` — causal world kernel
- `world-state.json` — persistent reality state
- `world-state.json.representation` — spatial intermediate representation (SIR)
- `dynamics.html` — observer for confirmed state-to-state dynamics
- `appearance-scene.js` — local state/dynamics → visual scene-packet translator
- `appearance-decoder.json` — Layer 3 appearance contract
- `index.html` — observer shell for State, Dynamics, Appearance, and Ω output mode

Layer semantics:

1. **State** — what exists, where, and in what condition.
2. **Dynamics** — what is happening and how confirmed state changes are represented continuously.
3. **Appearance** — photographic translation of State + Dynamics for an observer.

**Ω is an output mode, not a world layer.**

No observer may create, delete, relocate, or write back causal entities. Unknown geographic or physical facts remain provisional until calibrated from attributable sources.
