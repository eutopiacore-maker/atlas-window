# Third-party components

Atlas Layer 3 optionally loads the browser neural style-transfer models from `reiinakano/arbitrary-image-stylization-tfjs`.

- Project: https://github.com/reiinakano/arbitrary-image-stylization-tfjs
- License: Apache License 2.0
- Copyright notice retained from the upstream project.
- Atlas modifications: the upstream browser model is used only as a 2D frame-to-frame visual translator. Atlas does not use it to alter causal world state.

TensorFlow.js is loaded from its published browser distribution and is licensed under Apache License 2.0.
