# Legacy world pipeline reference

**Deprecated. No pipeline architecture is active here.**

The live world is **Atlas Reality Stack v6** under Rizoma Ω: shared prior snapshot, causal nodes, typed relations, synchronized deltas, feedback and persistent state.

Current authoritative surfaces:

- `world-engine.js` — causal world kernel
- `world-state.json` — persistent reality state
- `world-state.json.representation` — spatial intermediate representation (SIR)
- `index.html` — observer-only visual decoder

The renderer may infer appearance but may not create, delete or relocate world entities. Unknown geographic facts remain provisional until calibrated from attributable sources.

`WORLD_PIPELINE.md` remains only as a compatibility filename for old links. It has no architectural authority.
