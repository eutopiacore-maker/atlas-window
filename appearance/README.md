# Atlas Reality Stack — Layer 2

Layer 2 is the photographic appearance observer. It consumes the causal spatial intermediate representation and may infer materials, clothing, faces, lighting and photographic texture, but it cannot create, delete or relocate causal entities or write state back into the world.

Current runtime modes:
- `reference-keyframe`: integrated photographic target when no neural decoder is configured.
- `live-decoder`: reserved for an external neural image service using the same scene packet contract.

Synthetic human identities are stable by causal entity ID. Real public faces are never copied into agents.
